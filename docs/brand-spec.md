# 弈路助手 · Brand spec v0

- 工作名：弈路助手
- 定位：静态阵容学习与对局旁读工具
- 视觉语言：黑曜石战术板 × 棋子编成卡
- 标识：自有八向棋盘标记，不使用 Riot、TFT 或腾讯官方 Logo
- 背景：`#090d0b`
- 面板：`#111813` / `#19231c`
- 文本：`#f2ebdd` / `#a8b3aa`
- 主操作与主C：`#d6a64a`
- 主坦与完成状态：`#58b995`
- 转阵与失败状态：`#d96b61`
- 正文：Hiragino Sans GB / PingFang SC / Microsoft YaHei
- 数字：DIN Condensed / SFMono-Regular / Consolas
- 间距：8px主节奏；卡内允许4px
- 圆角：4 / 8 / 12px
- 动效：120–180ms，仅反馈状态变化
- 禁止：圆形棋子头像、负坐标职责角标、大面积霓虹渐变、官方Logo、低于12px的普通说明文字

正式开源前，字体、游戏素材和第三方统计分别完成许可证与来源审查。
