## 数据隔离

```text
Riot 官方 API
  -> 维护者显式运行本地命令
  -> .private-data/riot-tft/manual-snapshot.json（原始私有快照）
  -> .private-data/riot-tft/manual-aggregate.json（匿名私有聚合）
  -> 两者均被Git忽略，不进入网页构建

人工审核的公开数据
  -> src/data/
  -> npm run build / npm run build:single
  -> GitHub Pages 静态镜像 + 离线单 HTML
```

Personal 或 Development Key 只允许验证接口、数据结构、限流和聚合逻辑。它们的原始数据与聚合结果不得写入 `src/data/`、`dist/`、`dist-single/`、GitHub Actions artifact、仓库或公开页面。

只有取得 Production Key 后，官方 API 聚合结果才可以经过人工审核、去标识化和质量检查，转写为公开静态快照。即使取得 Production Key，本项目也不启用每日定时更新；每次更新仍由维护者明确触发并审核后发布。

## 密钥边界

- 运行时仅从环境变量 `RIOT_API_KEY` 读取。
- 不在命令参数、配置文件、页面、本地存储、日志或错误信息中显示密钥。
- 代码与测试不得包含 `RGAPI-` 形式的真实密钥。
- 缺少密钥时，联网模式必须安全失败；离线夹具模式不需要密钥。

## 区服边界

Riot 官方 TFT API 不覆盖中国大陆腾讯服务器。私有报告必须保留实际平台与区域路由，不能标成“国服统计”。公开页面当前的“国服、白金以下”是中文玩法定位，不表示数据来自国服 API。
